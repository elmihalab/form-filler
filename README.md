# مُعبِّئ الاستبيانات — الإصدار 1.1

برنامج صغير يعمل داخل المتصفح. يأخذ بيانات الطلبات من ملف الإكسل الذي يخرجه برنامج الوزارة، أو من نموذج يكتبه الموظف بيده على الشاشة، ويملأ بها ملفات الوورد.
لا يُرفع أي ملف إلى الإنترنت. القوالب وملفات الإكسل والطلبات اليدوية وسجل الطلبات المنجزة تُحفظ في متصفح كل مستخدم على جهازه.

شعبة الشؤون العلمية في حلب

## مكان البرنامج في الموقع

ارفع هذا المجلد كما هو (`form-filler`):

- إن كان في مستودع الموقع مجلد اسمه `public`، فارفعه داخله: `public/form-filler/`
- وإن لم يوجد، فارفعه في الصفحة الرئيسية للمستودع: `form-filler/`

رابط البرنامج بعد النشر: `/form-filler/index.html`

## الجديد في الإصدار 1.1

- **التعبئة اليدوية:** نموذج على الشاشة تُكتب فيه بيانات الطلب، ثم يُنزَّل ملف الوورد فورًا أو يُضاف الطلب إلى القائمة. يعمل مع الاستبيانات التي لها ملف إكسل أيضًا.
- **البدء من قالب وورد:** للاستمارات التي ليس لها ملف إكسل، مثل أوامر التكليف. يقرأ البرنامج الوسوم من القالب ويصنع منها النموذج.
- **وسم التاريخ الهجري:** `{اليوم الهجري}`.
- **حقل «اختيار»:** إن وُجد في القالب `{الصفة=إمام}` و`{الصفة=خطيب}` صار الحقل قائمة منسدلة فيها «إمام» و«خطيب».
- **ربط تلقائي:** حين يُرفع ملف إكسل لاستبيان بدأ من قالب، تُربط أعمدته بالوسوم المتطابقة تلقائيًا.

## ملفات المجلد

| الملف | عمله |
|---|---|
| `index.html` | الصفحة نفسها |
| `style.css` | الألوان والخط والهوية البصرية |
| `app.js` | الواجهة: القائمتان، الإعداد، التعبئة اليدوية، التوليد |
| `engine.js` | المحرك: قراءة الإكسل، الوسوم، الشروط، التعبئة، الدمج |
| `storage.js` | الحفظ داخل المتصفح |
| `sw.js` | ليعمل البرنامج دون إنترنت بعد أول فتح |
| `templates.js` | القالب التلقائي وخطاب التوجيه الافتراضي |
| `lib/` | مكتبتا PizZip وdocxtemplater (رخصة MIT) |
| `fonts/` | خط قمرة (الوزن المتوسط) |
| `assets/` | شعار العقاب والأيقونات |

## ملاحظة عن الخط

تستعمل الصفحة خط قمرة المثبَّت على الجهاز إن وُجد، وإلا تستعمل الوزن المتوسط المحفوظ في `fonts/`.
